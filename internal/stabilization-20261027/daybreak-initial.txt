## Actionable findings

- **Low — relative-path parsing accepts noncanonical delimiter variants.** [parser.ts:762](/private/tmp/foldkit-preview-stabilization-20261027/security/source/packages/foldkit/src/route/parser.ts:762) rejects literal `//`, but normalization at [parser.ts:767](/private/tmp/foldkit-preview-stabilization-20261027/security/source/packages/foldkit/src/route/parser.ts:767) can turn backslashes or stripped ASCII tabs/newlines into repeated leading slashes. The route parser subsequently removes empty segments, so input such as `/\people/ada` may be classified as the local `/people/ada` route instead of falling back. Preconditions: attacker-controlled redirect/path input and a consumer treating parse-versus-fallback as an allowlist boundary. Consequence: malformed network-path-like input can be accepted as a local typed Route. This helper does not itself navigate or return the raw target, so this is not a direct open redirect. Smallest repair: reject backslashes and URL-stripped whitespace before parsing, then verify the parsed sentinel origin and that the normalized pathname begins with exactly one slash; add boundary fixtures.

- **Low — raw subsequent `?` characters can be discarded before query validation.** `parsePathWithFallback` uses `Url.fromString`; [url/index.ts:69](/private/tmp/foldkit-preview-stabilization-20261027/security/source/packages/foldkit/src/url/index.ts:69)–[70](/private/tmp/foldkit-preview-stabilization-20261027/security/source/packages/foldkit/src/url/index.ts:70) split the reconstructed href on every `?` and retain only the first query portion. Preconditions: attacker-controlled path containing an unencoded second `?`, such as `/search?query=allowed?rejected`, and a query Schema used as a validation boundary. Consequence: the suffix is omitted rather than validated, potentially converting a rejected value into an accepted typed Route. Correct nested encoding avoids this, and typed-route rebuilding prevents raw-target navigation. Smallest repair: construct `Url` directly from the WHATWG URL properties or split only at the first delimiters; cover raw subsequent `?` values.
