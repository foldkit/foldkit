## Intentional distinctions

Query's factory can specialize a public contract through its handler generator
or factory-specific handler selection before Binding. Ordinary Block handlers
are selected through the curried Layer transformer. UI factories retain
`makeBlock` because they produce public contracts.

Native completion controls and historical experiments remain available for
comparison. Production apps use the unified API. Preserved `probe/` captures
include intentionally invalid inputs and unchanged compiler-workload copies;
they are excluded from app-style lint and formatting like the existing
`internal/` research captures. Normal framework declaration and compiler gates
remain enabled.

Effect lint keeps its ordinary application and accepted-consumer checks. Its
unknown-channel diagnostic is excluded at erased host implementation boundaries
and runtime tests that deliberately pass invalid contracts. Rejected declaration
fixtures also exclude floating-Effect warnings: those files prove invalid calls
at compile time rather than execute them. Their TypeScript rejection checks
remain enabled. The packed entrypoint smoke now uses the current Block/Layer
pair instead of the native assembly control.
